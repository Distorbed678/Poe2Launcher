# Changelog

## 0.3.0

- **Mod system, launcher half.** Mods are classified `client` / `server` / `both` (badge on every mod); the launcher now parses `mod.toml` with the shared `poe-hook-mods` crate (manifest v1 and v2; its own parser is gone), refuses a server-only mod with a clear message and installs only the client half of a `both` package. Every package is checked with `verify_package` (SHA-256, name, paths, links, limits, CRCs) before it is kept; a failed check installs nothing. A DLL mod without `game.hook_api` is now refused (the loader refused it anyway).
- **Mod cache and per-server mod sets.** `<data>/mods/cache/<id>/<version>/` keeps several verified versions; each server profile has its own set (the server's required mods always on, your own mods only where you enable them, or for all servers); at Play the set is copied into the game's `poe-hook-mods/` with `state.toml`. The official (read-only) entry never loads mods. **Breaking:** mods installed with older launchers in `<install>/poe-hook-mods/` are not read as the store any more (they are left alone and not enabled; add them again as a folder or package).
- **Mod sync with servers.** The optional `mods` list of `GET /api/v1/server` (id, version, side, SHA-256, size, required, hook_api, game versions, sources) is compared with the cache when a server is selected and before Play. Settings, *Mod sync*: **Off** (show what is missing, block Play), **Ask** (default; a dialog with name, version, side, size and a code warning, Download) or **Auto** (download, verify, switch; code mods included). Downloads come from the server (`/api/v1/mods/{id}/{version}.zip`) or the advertised https addresses, must match the advertised SHA-256, and are never kept on a mismatch. Plain-http rules apply. Old servers without `mods` work unchanged.
- **Mod browser** (Library, Mods, Browse): the index `index.json` of `Distorbed678/Poe2Mods` (schema, validator and CI in `docs/mod-index-template/` of Poe2ModdingProject), cached and quiet offline; search, filter by side, tag and game version; install a version into the cache and enable it for the selected server or all servers. Settings: cache size and **Clear unused cached mods**.

- **New layout (Home first).** Sidebar: Home, Servers, Host, Library, Settings (About is the small link at its foot). *Account* is merged into Servers (log in, create an account and log out inside each server's card); *Install* and *Mods* are merged into Library (tabs Game, Mods, Logs; the Client hook card is on Game). Old `#/account`, `#/install`, `#/mods` links open the new places. The Play bar stays on every page except Home, which has the big Play button.
- **Home.** The selected server with live status (online, players, ping measured by the launcher, client version, compatibility, uptime), the big Play button with the reason and a link when Play is blocked, the *Get ready to play* checklist and **News**: release notes of Poe2Launcher, Poe2ModdingProject (`server-v*`) and Poe2ClientHook (`hook-v*`) from the GitHub releases API plus `news.json` from the main repository (schema in docs/guides/launcher.md), cached and quiet offline or when rate limited; below it the selected server's message of the day if `GET /api/v1/server` sends an optional `motd`. Text is rendered from a markdown subset as plain text (no HTML), only https links open, in the system browser.
- **Server browser** (Servers, Browse): the public list `servers.json` of `Distorbed678/Poe2ServerList`, validated entry by entry and cached; the launcher asks each listed server itself (players, client version, ping; in parallel, short timeouts); filter by game version, search, tag, region, online only; sort by players, ping or name; *Add to my servers* (plain-http warning applies). Local and private addresses in the list are refused.
- **Logs** (Library, Logs): game logs, the hosted server's log and crash dumps; search, highlight, filters, open folder, and **Copy for a bug report** (system information and the last lines, with the home folder, account names, tokens and long hex strings redacted).
- **Better downloads:** pause and resume of the game install (DepotDownloader is stopped and started again with the same arguments plus `-validate`), speed and time left from the progress output, and a **disk-space check** before installing (refuses with how much is needed, free and to free up). The client hook and server package downloads show speed and time left.
- **Server backups** (Host): one-click backup of the hosted server's database with SQLite's online backup API (works while the server runs), list with date, kind and size, restore (server stopped, confirmation, the current database is backed up first), delete, and an automatic backup before each start keeping the last N (`rusqlite` 0.37, bundled SQLite, new dependency).
- **Server restart supervision:** the generated config has `[server] restart_mode = "exit"`; when the server exits with code 75 (an admin's restart) without the launcher having asked for a stop, the launcher starts it again; more than 3 restarts in 30 s end as an exit. Stop waits 15 s (was 8 s) after SIGTERM before it kills the server, because the server now shuts down gracefully (about 5 s).
- **Client hook download.** The launcher gets the hook DLLs itself: the *Client hook* card on the Install page downloads the newest stable release of Poe2ClientHook for the selected game version (Official (read-only) uses the newest private version's hook), checks the archive against its `.sha256` and every file against `release.json` (refuses unlisted files, unsafe paths, links, a wrong game version), installs it in its own data folder per hook version and uses it for Play automatically; the files are checked again before each deploy. It shows the installed version, "update available" and a Download / Update button. Settings, *Hook DLL directory* stays as an advanced override that wins over the download. Play is blocked with "Get the client hook first" when there is no hook at all.
- **Get ready to play** checklist on the Servers page for a fresh launcher: 1. install the game, 2. get the client hook, 3. host a server or join one.

## 0.2.0

- New look: dark theme (light optional), sidebar and title bar, cards, status chips, progress bars, empty states, in-app dialogs, toasts, page transitions and hover/press feedback (all off with `prefers-reduced-motion`), a new About page.
- **Game version dropdown** in the title bar: every supported private-server version (from the embedded `versions/*.toml`, newest first) and, at the top, **Official (read-only)**. The choice is saved and drives the install folder (one per version), depots, verification, deploy, Play, Host a server's release filter and the server list; a server that reports another client version is marked incompatible (with *Switch*). Adding `versions/<v>.toml` adds an entry.
- **Official (read-only)**: plays on the official servers with the hook in observation mode (what `deploy-client --official` deploys: `mode = "official"`, `login_mode = "steam"`, empty `trusted_servers`, original gateway list, no token, no login), after a one-time risk confirmation; the install is the current official build in its own folder (and, on Linux, its own Proton prefix). Servers, Account, Host a server and Mods are hidden there.
- Settings: **Log out of Steam** (forgets DepotDownloader's remembered login and the saved account name; the tool now keeps its login in the launcher's own data folder on Linux), **Minimize the launcher while the game is running** (off by default), window frame choice, per-version install folders.
- New original app icon (`assets/icon.svg`, all sizes regenerated). Linux: the window's app id is `org.poe2modding.launcher`; the AppImage's bundled `.desktop` file matches it; Settings has **Install desktop entry** / **Remove** (`~/.local/share/applications` and the hicolor icon theme) so the Wayland compositor shows the icon.
- Custom window frame (no system decorations): own title bar with minimize / maximize / close, drag and double-click to maximize, resize handles; Settings can switch back to the system frame.
